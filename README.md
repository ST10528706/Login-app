A java login system with username, password, and cell phone number validation.

Features
- Username validation ( must contain underscore, max 5 characters)
- Password complexity validation (min 8 characters, capital letter, number, special character)
-  South African cell number validation
-  User registration and login
-  Junit tests covering all validation

How to run
Open in NetBeans and run 'main.java', or 'ant test' to run the JUnit tests.
